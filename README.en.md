# hr_ai_robot

#### Description
HR机器人招聘助手，是一款基于Workbuddy或者Deepseek Harness的自动化机器人程序，实现了和企业内部飞书的对接；能够实现招聘简历的规则筛选，自动分类处理，以及内部飞书信息传达和转发的功能；
